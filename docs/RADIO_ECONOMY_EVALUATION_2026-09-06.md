# 라디오 저비용 분석 실제 방송 비교 — 2026-09-06

## 판정

**운영 교체 보류. 저가 모델 전면 교체는 품질이 나빠졌으며, 짧은 멘트 음성 + Gemini Flex + DeepSeek 조합은 후속 개선의 유망한 기준안이다.**

이번 평가는 실제 보관된 방송 약 4시간을 대상으로 유료 API를 직접 호출했다. 현재 구현 결과를 후보 모델 입력에 넣지 않았다. 현재 결과와의 일치율을 정답률로 부르지 않으며, 모든 곡의 정밀 경계를 사람이 청취해 확정한 시험도 아니다. 테스트 결과를 운영 보관함에 덮어쓰거나 서버 설정을 변경하지 않았다.

## 자료와 비교 방법

2026-09-05 KBS 1FM 두 방송의 조립된 원본을 사용했다.

| 방송 | 실제 파일 길이 | 현재 구현의 트랙 수 | 로컬 음성 감지 후 전송량 |
|---|---:|---:|---:|
| FM 실황음악 | 7,180.651초 | 4 | 422.900초, 약 7분 |
| 당신의 밤과 음악 | 7,180.544초 | 16 | 1,694.444초, 약 28분 |
| 합계 | 약 239분 | 20 | 약 35분, 전송 시간 85.3% 감소 |

현재 구현의 20곡은 정답 개수가 아니다. 이 비교에서도 추가 곡 후보와 잘못된 경계를 발견했다.

1. 기존 로컬 Qwen3-ASR 출력 전체를 Qwen3.8 Flash와 DeepSeek V4 Flash 0731에 각각 제공했다. 기존 Gemini 메타데이터는 제공하지 않았다.
2. 로컬 전사에서 소개 키워드를 포함한 120초 창을 합치고 앞뒤 5초를 보존하여 MiMo-V2.5로 직접 청취했다. 이 선택 방식은 소개를 누락해 탈락했다.
3. 원본에 Silero VAD 6.2.1을 CPU로 실행했다. 임계값 0.35, 음성 앞뒤 8초를 보존하고 최대 300초로 나눴다. Gemini의 기존 시각은 구간 선택에 사용하지 않았다.
4. 선택된 모든 음성을 Gemini 3.8 Flash의 실제 `google-ai-studio/flex` 공급자로 처리했다. 결과 전사문을 DeepSeek, Qwen, Gemini에 각각 같은 추출 지시와 함께 제공했다.
5. DeepSeek 결과에 현재 운영 코드의 공식 자료 검증기 `AlbumQuality.verify_metadata`를 적용했다. 자동 검색과 출처 검증도 실제 호출했다.
6. 곡 수·시각 판단이 엇갈린 여섯 구간을 Gemini Flex로 추가 청취했다. 이는 불일치 조사이며, 추가 응답 자체를 독립 정답으로 삼지 않았다.

로컬 ASR은 저장된 출력을 재사용했다. 따라서 이번 시험으로 GPU 전사 처리 속도나 하루 19~20시간 처리 능력을 입증한 것은 아니다. 실제 도이치 번호가 등장하는 방송 사례도 이 표본에 없어 그 항목은 미검증이다.

곡 수가 같은 것은 같은 곡을 찾았다는 뜻이 아니다. 예를 들어 DeepSeek 로컬 전사 결과는 로드리고 두 악장을 합치면서 마지막 곡 후보를 추가해 현재 구현과 같은 16곡이 되었다.

### 확인한 구체적인 오류와 회복

- **브루크너 아베 마리아:** Qwen은 현재 소개에서 합창으로 구분한 곡에 BBC 스코티시 심포니 오케스트라를 추가했다. 다음 곡의 출연진이 섞인 사례다. DeepSeek의 VAD 혼합안은 BBC 싱어즈만 보존했다.
- **마니피캇:** 로컬 전사 → DeepSeek는 Ryan Wigglesworth, Sophie Bevan, BBC Singers, BBC Scottish Symphony Orchestra를 복원했다. MiMo 입력에서는 이름이 ‘라이언 윌솔스’, ‘소피 레번’으로 악화됐다. 작품과 공연 구성은 [출판사 Schott](https://www.schott-music.com/en/magnificat-no453537.html)의 기록과 대조했다.
- **로드리고:** Qwen 로컬 전사 결과는 ‘어느 귀인을 위한 환상곡’을 ‘아랑훼즈 협주곡’으로 바꿨다. VAD 혼합안의 DeepSeek는 작품과 두 악장을 올바르게 구분했다. 연주 조합은 [로드리고 공식 아카이브 검색 결과](https://www.joaquin-rodrigo.com/index.php/es/archivo-musical/item/396-resplandor-de-la-guitarra)와 대조했으며, 원문 페이지 직접 접속은 시간 초과였다.
- **필립 글래스:** Qwen 로컬 전사는 에튀드 번호를 5번으로 만들고 연주자를 제대로 복원하지 못했다. VAD 혼합안은 에튀드 2와 NYU를 보존했다. NYU의 녹음 여부는 [작곡가 공식 기록](https://philipglass.com/glassnotes/the-piano-etudes-recordings/)을 확인했다.
- **앨리스 사라 오트:** Gemini의 짧은 음성 청취도 ‘엘사 라우트’로 들었다. DeepSeek가 이를 그대로 옮겼으나 후속 공식 자료 검색에서 Alice Sara Ott로 교정됐다. [Deutsche Grammophon 공식 자료](https://www.deutschegrammophon.com/en/artists/alicesaraott/news/world-premiere-recordings-of-haunting-new-piano-versions-of-works-by-johann-johannsson-performed-by-alice-sara-ott-277169)가 근거다. 다만 ‘Beauty’와 ‘The Theory of Everything’을 한 제목으로 합친 문제는 남았다. 같은 전사를 받은 Gemini도 Beauty의 영화 정보를 잘못 연결했다.
- **풀랑크:** 혼합안은 루이 로르티·에드워드 가드너·BBC 필하모닉을 유지했다. [Chandos/Naxos 음반 정보](https://www.naxos.com/CatalogueDetail/?id=CHAN10875)와 일치한다. FP 146을 ‘작품 146’으로 표기한 문제는 남았다.
- **사랑의 찬가:** 현재 결과에는 마르게리트 모노가 들어 있지만 새 혼합안은 두 버전 모두 작곡가가 빈 값이다. 공식 검색을 수행했어도 현재 출처 검증기를 통과하는 교정이 반환되지 않았다. 명확한 품질 후퇴다.
- **The Longest Summer:** 현재 구현에는 없지만 혼합안은 마지막 소개와 클로징에서 곡 후보를 회수했다. 작곡가와 정확한 트랙 경계는 미확정이다.
- **소개되지 않은 노래:** 방송 후반에 로컬 ASR이 노래 가사를 반환하고 추가 짧은 청취에서도 여성 보컬을 감지했으나, 소개 멘트 중심의 혼합안에는 별도 미확인 트랙으로 보존되지 않았다. 멘트가 없다고 실제 음악까지 빠지는 문제가 있다. 가사로 연주자를 확정해서 해결할 수 없다.

이것은 일부 구체 사례에 대한 근거 대조다. 전곡·전필드의 검증된 정답 세트가 없으므로 종합 정확도 백분율은 산출하지 않았다.

## 시간과 곡 경계 — 통과하지 못한 항목

기존 전체 청취에서도 1,180.544초 첨부에 1,500.584~1,551.492초, 1,821.151~1,842.170초라는 소개 시각이 반환됐다. 실제 마지막 소개가 원본 밖으로 밀려나는 원인이다.

짧게 나누는 것만으로도 해결되지 않았다. 새 VAD 청취에서도 107초 첨부에 124.646~138.835초, 167.6초 첨부에 끝 239.308초, 150.5초 첨부에 끝 217.51초 등 **범위를 벗어난 소개 3건**이 발생했다. 이번 시험은 이를 검출해 보고했으며 정상 경계로 인정하지 않았다.

추가 짧은 청취에서는 현재 헨델 아리아 시작 6,242.4초와 달리 약 6,019초에 피아노에서 첼로·피아노로 전환하는 후보가 나왔다. 모델 간 약 223초 차이이므로 확정 경계가 아니라 재검토 대상으로 분류했다. 브루크너 합창 구간에서는 악기 추가를 곡 변경처럼 나누는 응답도 있어, 추가 모델 호출만으로 경계를 확정하면 안 된다.

필요한 통과 조건은 다음과 같다.

- 첨부 범위 검증 실패 시 숫자를 억지로 잘라 맞추지 않고 해당 시각을 폐기한다.
- 연속 음악 중 다른 곡·다른 연주 버전으로 넘어가는 구간을 별도로 탐지한다.
- 소개에서 찾지 못한 음악은 미확인 트랙 후보로 남기고 완성 음반 처리하지 않는다.
- 실제 청취로 정한 경계 표본과 비교해 첫 음·잔향이 잘리는지 확인한다.

실패 시도, 비교 모델, 추가 경계 조사까지 **이번 시험에서 확인된 총 API 비용은 $0.175717, 환율 1,400원 가정 약 246원**이다. 별도 HTTP 400 요청 한 건은 비용 정보가 반환되지 않았다. 전기·결제 수수료·세금은 제외한다.

새 메타데이터 소계만 방송 길이로 월 580시간에 단순 비례하면 약 $18이다. 실제로는 검색 빈도·방송 수·경계 확인·재검토가 추가되므로, 앞서 제안한 월 $10~25를 검증 완료된 전체 운영비로 확정할 수 없다.

## 다음 구현에 대한 권고

DeepSeek를 저가 후보 정리에 사용하고, 모든 안내 멘트는 Gemini Flex가 직접 확인하는 구성이 가장 유망하다. MiMo의 한국어 직접 음성 처리와 Qwen의 최종 곡명 확정은 이번 표본에서 채택하지 않는다. 모델의 `uncertain=false`만으로 확정하지 않고, 작품번호·연주자 근거와 미확인 음악 구간을 검증해야 한다.

현 상태는 비용 절감 가능성을 확인한 시험이며 품질 동등성 입증은 아니다. 경계 검증과 미확인 곡 보존이 갖춰진 뒤 운영으로 옮기는 것이 맞다.

## 재현과 보관

평가 실행기는 `local-analysis/evaluate_economy.py`이다. 운영 서버와는 연결하지 않고 사용자 데이터 폴더의 `economy-evaluation-2026-09-06` 아래에 입력·응답·시각·실제 비용·모델 및 공급자 정보를 저장한다. API 키는 기존 로컬 `.env`에서 메모리로 읽고 응답 기록이나 저장소에 넣지 않는다.

```powershell
$env:PYTHONIOENCODING='utf-8'
python local-analysis/evaluate_economy.py prepare
python local-analysis/evaluate_economy.py text --model deepseek --no-thinking
python local-analysis/evaluate_economy.py text --model qwen --no-thinking
local-analysis/.venv/Scripts/python.exe -m pip install --no-deps --target local-analysis/.runtime/evaluation silero-vad==6.2.1
local-analysis/.venv/Scripts/python.exe local-analysis/evaluate_economy.py vad
python local-analysis/evaluate_economy.py audio --model gemini --vad-clips
python local-analysis/evaluate_economy.py reconcile --audio-model vad-gemini --model deepseek --no-thinking
python local-analysis/evaluate_economy.py verify
python local-analysis/evaluate_economy.py summary
```

새 유료 요청은 명시한 단계에서만 발생한다. 같은 요청의 성공 응답을 재사용하고, 미완료 요청을 자동 재호출하지 않는다. 요청 단위 사용량의 누적 확인액이 $2 이상이면 다음 평가 단계 시작을 중지한다. 진행 중 요청의 확정 전 요금까지 강제 차단하는 결제 한도는 아니다.

Python 테스트 56개 통과. 이 중 추가한 6개는 실제 발생한 JSON 앞뒤 설명, 음성 미인식 응답, 중복 비용 집계 및 실패 요청 재결제 방지를 검증한다. 운영 UI·예약·녹음 서버의 동작은 변경하지 않았다.
