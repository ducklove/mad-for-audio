# 기기 디자인 평가 · v175 · 2026-09-05

[전후 화면 비교 열기](design-review-2026-09-05.html)

공개 기기 24종과 추가 마감 2종을 검토했다. 아래 점수는 이번 작업에서 적용한 **주관적 화면 디자인 평가**다. 사용자 테스트 결과, 접근성 인증, 실물 복각 정확도의 인증 점수가 아니다. v127의 실물 식별성 중심 평가와 직접 비교하지 않는다.

## 평가 기준

정렬·배치 / 가독성 / 재질·입체감 / 색·조명 / 조작 일관성, 각각 20점. 90점은 주요 텍스트 충돌과 잘림이 없고 기기별 재질과 조작 위계가 안정적인 수준으로 정의했다. 작은 장식 인쇄와 일부 복잡한 금속 반사에는 개선 여지가 있어 95점 이상은 부여하지 않았다. E-303은 기존 90점을 유지한다.

초기 점수는 수정 전 캡처, 최종 점수는 수정 후 단품·실제 랙 크기의 캡처와 회귀 테스트를 근거로 판정했다. 모바일 390px에서는 전체 배치와 조작 흐름을 별도 확인했으며, 축소된 랙의 모든 미세 인쇄가 본문 크기로 읽힌다는 뜻은 아니다.

## 모델별 근거

- **Yamaha T-2** — 감점: 노브의 보라색 반사와 둥근 플라스틱 인상. 개선: 차콜·알루미늄 반사, 테두리와 측면 요철을 정돈.
- **McIntosh MR78** — 감점: 작은 기능 인쇄와 노브 색의 불일치. 개선: 미세 인쇄 확대, 노브의 중성 금속색과 공통 접촉 그림자.
- **Marantz Model 10B** — 감점: 주파수 눈금이 CRT를 가로지르고 선국 영역과 분리. 개선: CRT 오른쪽 독립 다이얼 창, 눈금·히트 영역·선국 좌표를 함께 수정.
- **GE-5** — 감점: 출력 레벨 제목이 LED 눈금과 겹침. 개선: 제목을 별도 기준선에 배치, 버튼 접촉 그림자 조정.
- **Sansui SE-9** — 감점: 메모리 키와 좌우 채널 인쇄가 작음. 개선: 프리셋 이름과 L/R 표시 확대, 글자 대비 개선.
- **Technics SH-8065** — 감점: 주파수 라벨 밀도와 첫 슬라이더 축 숫자 간섭. 개선: 대역 인쇄 확대, 축 숫자를 슬롯 바깥으로 이동.
- **McIntosh MC2105** — 감점: 미터의 원호·숫자·바늘이 혼잡함. 개선: 일관된 원호 기하로 눈금 재구성, 단위·제목·바늘 축 분리.
- **Marantz 8B Tribute** — 감점: 탁한 샴페인 패널과 낮은 기능 인쇄 대비. 개선: 패널 중간톤 정돈, 바이어스와 기능 인쇄 크기 개선.
- **Western Electric 91E Tribute** — 감점: 미터 브랜드 글자가 회전축과 충돌. 개선: 브랜드 인쇄를 바늘 축 위로 옮기고 공통 버튼 깊이 조정.
- **Accuphase E-303 Tribute** — 감점: 구조는 양호하나 작은 인쇄와 미터 조명은 개선 여지. 개선: 기존 패널 구획 유지, 공통 버튼 반사와 접촉 그림자만 정돈.
- **McIntosh MA2375** — 감점: 어두운 미터와 물결 같은 금속 반사가 경쟁. 개선: 미터 면 밝기 회복, 단위와 제목 축소·분리, 하부 금속 반사 정돈.
- **Nakamichi Dragon** — 감점: 보관함이 기기 패널과 다른 점선 카드로 보임. 개선: 패널과 이어지는 얕은 서랍, 작은 손잡이와 명료한 보관 안내.
- **Revox B215** — 감점: 큰 아이콘과 평평한 카세트 창. 개선: 아이콘 크기·기준선 통일, 기능명 추가, 카세트 셸·체결부 표현.
- **Tandberg TCD 3014A** — 감점: 조작부 아이콘이 과대하고 카세트 외곽이 모호함. 개선: 조작 행과 라벨 정렬, 성형 셸과 하단 구조, 보관 서랍 정돈.
- **Pioneer CT-F1250** — 감점: 전송 키 아이콘 크기와 빈 보관 영역의 밀도. 개선: 기능명·아이콘 위계 조정, 셸 층과 공통 서랍 반영.
- **TEAC W-990RX** — 감점: 하단 보관함의 점선과 저대비 안내. 개선: 서랍 형태와 안내 대비 정돈, 기존 양면 카세트 구조 유지.
- **Technics SL-1200MK2** — 감점: 플래터가 모델 설명을 가리고 음반 반사가 과함. 개선: 모델명 간결화, 촘촘한 홈과 절제된 반사, 하단 면과 이미지 대체 표지.
- **Thorens TD 124** — 감점: 클리닝 표시와 속도 눈금 간격 부족. 개선: 클리닝 행 이동, 음반 홈·하단 면 개선, 표지 로딩 실패 처리.
- **Garrard 301** — 감점: 성긴 음반 홈과 평평한 하단 경계. 개선: 음반 홈과 반사 밀도 조정, 하단 그림자 면과 표지 폴백.
- **Linn Sondek LP12** — 감점: 금속 상판 위에 나뭇결이 겹치고 모델 설명이 잘림. 개선: 목재·금속 레이어 분리, 모델명 정리, 홈·반사·받침 깊이 개선.
- **DT-540 · 검정/은색** — 감점: 기울어진 시간 숫자와 흐린 대기 표시. 개선: 직립 고정폭 숫자, 초 단위 간격, 대기 상태 대비와 발광 번짐 조정.
- **Victor V** — 감점: 밝은 음반 라벨에서 글자가 사라지고 긴 제목이 넘침. 개선: 배경에 따른 잉크색, 폭에 맞춘 말줄임과 원문 보존, 축 주변 글자·노후 질감 정돈.
- **A501 · 차콜/민트** — 감점: 오염 효과가 금속과 패널을 가리고 설명이 빽빽함. 개선: 부식·얼룩 강도 조절, 밴드 설명 크기 정돈, 두 마감 확인.
- **Lasonic TRC-931** — 감점: 작은 기능명과 긴 테이프 제목의 넘침. 개선: 주요 인쇄 대비·크기 조정, 제목과 연주자 폭 제한 및 원문 보존.

## 검토 범위와 검증

최종 로컬 검증: `npm test -- --workers=4` — **117개 통과, 실패·재시도 없음** (Chromium 전체, WebKit 핵심 흐름 및 새 디자인 회귀). 카탈로그 사전 검사와 `git diff --check`도 통과했다.

- SVG 렌더러, 공통 조명, 선국 좌표, 음반·테이프 라벨, 타이머 표시, 재킷 로딩, 카탈로그와 서비스워커 버전을 점검했다.
- Chromium·WebKit의 24종 단품 및 두 추가 마감, 대표·검정·은색 랙을 캡처했다. 실제 랙 폭 1166px와 모바일 390px 배치도 확인했다.
- 단품 비교는 동일한 조명 조건을 만들기 위해 캡처 도구가 전원 표시를 강제한다. 시간·미터·릴의 순간 상태 차이는 디자인 변경이 아니다. 기능 검증은 별도의 모의 미디어 테스트로 수행했다.
- 새 회귀 테스트는 10B 눈금과 실제 선국 좌표, 밝고 어두운 라벨·긴 제목, 재킷 이미지 실패와 복구를 두 브라우저에서 확인한다.
- 기존 재생·녹음·예약·저장·모델 전환·키보드·모바일·서비스워커·트레이 메시지 경계 테스트를 실행했다. 오디오 파라미터 전환과 iframe 초기화의 고정 지연 의존도도 제거했다.
- 실제 방송사 스트림 전체, 물리적 iPhone·Mac·Windows 트레이 패키지의 설치 실행은 이번 검증 범위에 포함하지 않았다.
- README의 음반 수를 현재 카탈로그(86장, 494트랙)에 맞추고 정적 자원 버전을 v175로 동기화했다.
