# 실물 대조와 전면 재설계 · v176

[전후 비교 페이지](design-review-2026-09-05.html)

## 기존 판정 정정

v175의 24종 전체 90~93점 판정을 철회한다. 텍스트 충돌과 작은 마감 위주로 검사하면서 실물의 구획·비례·부품 종류가 다른 문제까지 통과시켰다. MC2105의 미터 위치, B215의 은색 상단, TCD 3014A의 표시 방식이 대표적인 누락이다.

**이번에도 전 모델 90점 달성을 선언하지 않는다.** 구조 재설계 3종, 표시·조작 정합 수정 1종, 화면 구성 변경 4종을 구현했다. 나머지 16종은 현재 렌더링을 보수적으로 재평가했으며 이번 변경에서 외형을 고치지 않았다. 목표와 실제 완료 범위를 구분한다.

## 기준과 한계

실물 구조·비례 30 / 배치·정보 위계 25 / 재질·입체감 20 / 실제 크기 가독성 15 / 조작 정합 10으로 평가했다. Tribute 모델은 실물 복각 대신 내부 시점·광원·조형의 일관성을 첫 항목에 적용했다.

90점은 합계만으로 통과시키지 않는다. 주요 부품 종류와 위치가 실물에 맞고, 근거 사진의 방향·모델이 확인되며, 일반 화면과 모바일에서 주요 정보와 조작이 읽히고, 표시와 클릭 위치가 일치해야 한다. 구조 오류가 큰 기존 B215·TCD3014는 50점 미만으로 재평가했다.

점수는 여전히 작성자의 휴리스틱이며 측정값이 아니다. 1~2점 차이는 순위 근거가 약하다. 레퍼런스 재대조가 끝나지 않은 모델은 잠정 점수다. 기하·동작 테스트는 특정 결함의 부재를 확인할 뿐 미적 완성도를 보증하지 않는다. 아래의 이전 점수는 v175 화면을 새 기준으로 다시 평가한 값이며, 과거에 공표한 점수가 아니다.

## 수정한 8종

### McIntosh MC2105 · 62 → 85

- 확인한 문제: 실물과 달리 미터가 로고 양쪽으로 갈라져 있었고, 패널이 지나치게 낮았다. 파워 앰프 전면에 앱 마스터 볼륨이 섞여 있었다.
- 구현: 왼쪽 듀얼 dB 미터·오른쪽 브랜드·하단 5노브로 전면을 새로 구성했다. 본체 가로세로비는 약 2.36:1로 바꾸고 앱 공통 음량을 밖으로 분리했다. METER RANGE를 실제 조작에 연결했다.
- 남은 감점: 로고는 원래의 전용 서체와 다르다. 노브의 금속 반사와 미터 인쇄 간격은 사진과 차이가 있어 복각 완성으로 평가하지 않는다.
- 세부 점수: 25 / 23 / 16 / 12 / 9
- 근거: [McIntosh 공식 정면 사진](https://www.mcintoshlabs.com/legacy-products/amplifiers/MC2105)

### Revox B215 · 48 → 85

- 확인한 문제: 범용 검정 패널에 오른쪽 LED를 붙여 B215의 은색 상단, LCD, 상단 트랜스포트를 모두 놓쳤다.
- 구현: 은색 상단에 왼쪽 LCD와 오른쪽 조작 키를 배치하고, 검정 하단 중앙에 카세트와 양쪽 격자 키패드를 구성했다. LCD 세그먼트는 발광하지 않게 바꾸고 보관함·녹음 입력을 별도 하단 영역으로 분리했다.
- 남은 감점: 하단 키의 수·배열과 일부 명칭은 앱의 기존 기능에 맞춘 변형이다. 작은 인쇄와 사출 키의 눌린 깊이는 더 정교하게 다듬어야 한다.
- 세부 점수: 24 / 23 / 16 / 13 / 9
- 근거: [정면 실물 사진 · Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Revox_B215_cassette_deck.jpg)

### Tandberg TCD 3014A · 45 → 81

- 확인한 문제: 실물에 없는 두 아날로그 바늘 미터와 왼쪽 4노브를 그려 모델의 구조 자체가 달랐다.
- 구현: 왼쪽 카세트·오른쪽 가로 레벨 표시·그 아래 원형 트랜스포트 키와 하단 조정 노브로 재구성했다. 큰 출력 노브를 오른쪽에 두고 앱 보관함을 밖으로 옮겼다.
- 남은 감점: 확보한 제조사 사진의 해상도가 낮아 작은 각인까지 확인하지 못했다. 키의 개수·기능명과 목재 마감은 앱 재해석이며, 아직 90점을 줄 근거가 부족하다.
- 세부 점수: 22 / 23 / 15 / 12 / 9
- 근거: [Tandberg 제조사 1985년 카탈로그 · 6쪽](https://snw.lonningdal.no/tandberg/catalogs/TandbergCatalog1985_US.pdf)

### McIntosh MA2375 · 68 → 86

- 확인한 문제: 두꺼운 가상 미터 테두리, 과도한 표시창 문구, 투명하게 보이는 케이지가 실제 인상을 흐렸다. 확대된 본체에 톤·입력 조작 좌표가 따라오지 않았다.

- 남은 감점: 상판 반사와 진공관 내부 구조는 여전히 단순화되어 있다. 실물과 같은 재질감을 확보했다고 판정하지 않는다.
- 세부 점수: 25 / 23 / 17 / 12 / 9
- 근거: [공식 제품 페이지 + 사용자 정면·측면 사진](https://www.mcintoshlabs.com/products/integrated-amplifiers/MA2375)

- 남은 감점: 현재 공통 회전·톤암 기하를 사용하므로 플래터와 본체 비율, 톤암 피벗 위치는 실물과 차이가 남는다. 전면 비례까지 완성한 복각은 아니다.
- 세부 점수: 22 / 24 / 16 / 13 / 9

## 구조 변경의 사용성

- 턴테이블의 곡 목록은 SVG 미세 글자 대신 13px HTML 버튼이며, 모바일에서는 14px·높이 44px 이상으로 표시한다. 제목은 줄바꿈하고 13곡 이상도 목록 내부에서 스크롤한다.
- 전체 랙 몰입 모드에서는 본체만 표시한다. 턴테이블을 단일 확대하면 음반 정보와 조작이 다시 보이며 화면 높이를 넘으면 내부 스크롤을 사용한다.
