# 내 방송 음반 연결

독립 Radio Archive 서버에서 만든 음반을 수납장에서 재생한다. 이 앱에는 녹음·곡 분리·AI 분석 서버가 포함되지 않는다.

1. 같은 PC의 Radio Archive 관리 화면에서 음반을 만든다.
2. `내 음반 → mad-for-audio에서 듣기`에서 연결 링크를 열어 읽기 권한을 연결한다.
3. 앱 수납장의 음반을 선택하고 A/B면을 바꿔 듣는다. 카세트는 TRC-931에서 재생한다.

파일은 서버에 남으며 검토 필요·길이·파일 크기를 함께 표시한다. 연결은 30일간 유효하다. 서버 화면에서 해제하면 발급된 재생 주소도 무효화된다. 앱의 연결 삭제는 이 앱의 연결 정보와 목록을 지운다. 긴 일시정지나 API 서버 재시작으로 주소가 만료되면 곡을 다시 선택한다.

현재 서버 주소는 `http://127.0.0.1:8766`이며 서버와 같은 PC에서만 동작한다. 브라우저가 요청하는 로컬 네트워크 접근 권한이 필요할 수 있다. 미연결 상태에서는 로컬 서버를 자동 검색하지 않는다. 읽기 토큰만 전달하며 관리 토큰과 OpenRouter 키는 앱으로 전달하지 않는다.

`radio-archive-client.js`가 버전 1 음반 계약을 검증한다. 한 음반은 한 수납장 항목을 유지하고 면만 전환한다. 곡은 불변 버전을 참조하고 매번 제한된 재생 표를 받는다. 같은 버전의 파일을 여러 음반에서 공유한다. 서버 오류를 공개 음원의 대체 재생으로 숨기지 않는다.

`tests/radio-archive.spec.js`는 모의 API/합성 오디오로 권한 연결·면 전환·정지와 비동기 응답 경합·곡간 간격을 검증한다. 실제 방송 품질과 운영 연결은 Radio Archive의 별도 검증 기록에서 다룬다.
